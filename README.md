# Tidlom อี้จิง

เว็บแอฟเสี่ยงทายอี้จิงภาษาไทย ใช้ตัวบทโจวอี้ (周易) ฉบับจีนตัวเต็มคู่กับคำอธิบายภาษาไทย

## ความสามารถ

- เสี่ยงได้ 3 วิธี: เหรียญสามเหรียญ, ก้านหญ้า 49 ก้าน (大衍筮法 จำลองการแบ่งกองจริง 18 รอบ) และกรอกผลจากเหรียญจริง
- แสดงฉั่วต้น (本卦) และฉั่วปลาย (之卦) พร้อมตรีลักษณ์บนล่าง
- บอกว่าควรอ่านบทไหนตามจำนวนเส้นเปลี่ยน ตามกฎของจูซีใน 易學啟蒙
- ตัวบทครบ 64 ฉั่ว: คำพยากรณ์ประจำฉั่ว (卦辭), ภาพใหญ่ (大象), คำพยากรณ์รายเส้น 384 บท และ 用九/用六
- เตือนเมื่อถามคำถามเดิมซ้ำภายใน 24 ชั่วโมง ตามคำของฉั่วเหมิง 初筮告，再三瀆
- ตีความด้วย Claude ตามคำถามของผู้ถาม พร้อมถามต่อได้ ระบบส่งตัวบทของทั้งสองฉั่วและบทที่กฎจูซีชี้ไปให้ Claude อ่าน คำตีความเก็บรวมในประวัติ
- เก็บประวัติไว้ในเบราว์เซอร์ (localStorage)

## การตีความด้วย Claude

ใช้ความสามารถ `sample` ของ artifact บน claude.ai ซึ่งเรียก Claude ด้วยบัญชีของผู้เปิดหน้าเอง จึงไม่ต้องมี API key หรือเซิร์ฟเวอร์ ครั้งแรกที่กด ระบบจะถามผู้ใช้ให้อนุญาตก่อน

ถ้าเปิดแอฟจากที่อื่น เช่น `npm start` หรือ GitHub Pages จะไม่มี `window.claude` ส่วนตีความจะแสดงข้อความแจ้ง ส่วนอื่นใช้ได้ตามปกติ ถ้าจะให้ตีความได้นอก claude.ai ต้องเพิ่มเซิร์ฟเวอร์ที่ถือ API key ของ Anthropic เอง

พรอมต์และตัวแปลงคำตอบอยู่ใน `js/interpret.js` (ทดสอบได้ด้วย node)

## รัน

ไม่มีขั้นตอน build ใช้ ES modules ตรง ๆ จึงต้องเปิดผ่าน HTTP server

```sh
npm start        # python3 -m http.server 8000 แล้วเปิด http://localhost:8000
npm test         # ทดสอบข้อมูลและตรรกะด้วย node:test
```

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `js/divination.js` | ตรรกะล้วน: โยนเหรียญ, ก้านหญ้า, หาฉั่ว, กฎการอ่าน |
| `js/data/zhouyi.js` | ตัวบทจีน 64 ฉั่ว (สาธารณสมบัติ) |
| `js/data/th-upper.js`, `th-lower.js` | คำอธิบายไทย ภาคต้น 1 ถึง 30 และภาคปลาย 31 ถึง 64 |
| `js/interpret.js` | สร้างพรอมต์ตีความ, บทสนทนาถามต่อ, แปลงคำตอบเป็น HTML อย่างปลอดภัย |
| `js/app.js` | หน้าจอ |

ความน่าจะเป็นของวิธีก้านหญ้าไม่เท่ากับเหรียญ: หยินแก่ 1/16, หยางหนุ่ม 5/16, หยินหนุ่ม 7/16, หยางแก่ 3/16 ส่วนเหรียญได้ 1/8, 3/8, 3/8, 1/8 ชุดทดสอบตรวจสัดส่วนนี้ไว้
